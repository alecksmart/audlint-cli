## Exclusions applied

- Ordinary command details, dependency lists, UI behavior, individual codec safeguards, current R3 analyzer minutiae, sidecar names, and coding-style conventions were excluded.
- Profile normalization, analyzer output literals, quality JSON fields, exit-status composition, scan locking, and backup rotation mechanics were not promoted as separate candidates because the reviewed evidence did not show enough independent architectural value for this small set.
- SQLite helper ownership was folded into C1 and C2 instead of duplicating their state and identity boundaries.
- No speculative future architecture, inferred historical alternatives, or rationale based only on architectural plausibility was included.
