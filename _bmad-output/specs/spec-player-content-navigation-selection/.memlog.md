- (decision) Use the Functional Core / Imperative Shell paradigm: one Bash selector controller owns TTY effects, event dispatch, SQLite/player effect calls, and cleanup; one persistent Python model process owns pure selector semantics and session state. Binds CAP-1..CAP-7 and prevents Bash and Python from each becoming competing UI state machines.
- (decision) Freeze one session inventory identity/order snapshot after a complete filesystem walk and checked-state read; form it from live inventory plus persisted checked paths absent from the walk, marked unavailable. Python owns this immutable inventory and a mutable availability/measurement overlay until exit; only reopening rebuilds identities. This binds CAP-1/CAP-3/CAP-7 and prevents a redraw, projection, or failed measurement from silently changing the selectable universe.
- (decision) SQLite player_content_selection keyed by validated library-relative path is the only durable membership authority. The Python model owns expansion, view, focus anchor/current derivation, search draft/applied query, Help position, busy/result state, projection, viewport, and derived counts/sizes; Bash holds no competing semantic copy and refreshes the model only from committed effect results. This binds CAP-1..CAP-5 and prevents persistence/session-state conflation.
- (decision) All album and artist changes follow one intent-to-commit path: model emits a complete target-set replacement intent; Bash validates and measures every required addition through shared player snapshot helpers; one lib/sh/sqlite.sh transaction applies the full add/remove manifest; only successful commit acknowledgement changes model membership. Artist additions measure all new paths before BEGIN, artist removals include unavailable checked paths without measurement, and failures acknowledge nothing. Binds CAP-3 and prevents partial groups and divergent album/artist SQL paths.

- (decision) Centralize Unicode and display semantics in one importable Python terminal-text kernel used by the model: unicodedata NFC then full str.casefold for literal matching; one grapheme-boundary implementation for editing/truncation; display-cell width through a UTF-8 locale/runtime wcswidth probe exposed behind the kernel. Binds CAP-2/CAP-6 and prevents code-point, byte, and terminal-cell algorithms from diverging.
